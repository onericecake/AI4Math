# Problem

For every nonnegative integer `n`, prove that the sum of the first `n` odd positive integers equals `n²`:

`1 + 3 + ... + (2n - 1) = n²`.

For `n = 0`, the sum is empty and equals zero.

## Definitions

The sum means `Σ_{k=1}^n (2k - 1)`.

## Permitted assumptions

Elementary integer arithmetic and mathematical induction.

## Completion criteria

Give an argument valid for every nonnegative integer `n`, including the base case.
