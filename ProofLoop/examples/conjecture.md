# Problem

Decide whether, for every integer n >= 0, the integer n^2 + n + 41 is prime.
Give a proof or an exact counterexample with a proof that it satisfies the hypotheses
and contradicts the claimed conclusion.

## Permitted assumptions

Elementary integer arithmetic, divisibility, and the definition of a prime number.

## Completion criteria

For a proof, cover every nonnegative integer. For a refutation, give an explicit
nonnegative integer and a nontrivial factorization of the resulting value.
Finite searches and exact-arithmetic computations are permitted. A successful finite
search that finds no counterexample is not a proof of the universal claim.
No web search is needed. Preserve any useful partial results and clearly label them.

This is an intentionally small workflow demonstration, not an unsolved research problem.
